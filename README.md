# Flipkart Support Assistant

## Project Overview
This project implements an end-to-end Flipkart-style customer support assistant that combines classical machine learning, deep learning, retrieval-augmented generation, and agentic AI.

The system contains three connected components:

1. A return-risk prediction pipeline trained on a deterministic synthetic order-history dataset.
2. A product-image categoriser trained using transfer learning on Fashion-MNIST.
3. A LangGraph-based support assistant that can answer policy questions using a local knowledge base and can call both trained machine-learning models as tools.

The final support assistant connects the models from Parts 1 and 2 instead of treating them as independent exercises.

## Part 1 - Return Risk Scoring
Part 1 builds a return-risk prediction pipeline using a deterministic synthetic order-history dataset.

The pipeline includes:

- deterministic dataset generation
- exploratory data verification
- missing-value handling
- categorical encoding
- feature scaling
- DummyClassifier baseline
- Logistic Regression
- threshold analysis
- Random Forest
- GridSearchCV
- feature importance
- permutation importance
- subgroup analysis
- Random Forest threshold calibration
- model persistence

### Dataset Generation
The dataset is generated using the provided deterministic generator with:

- N = 6,000 orders
- NumPy random generator seed = 42
- Five product categories
- Four payment methods
- Thirteen columns

The dataset is generated by running:

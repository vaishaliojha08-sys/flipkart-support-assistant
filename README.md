# Flipkart Support Assistant

## Project Overview
This project implements an end-to-end Flipkart-style customer support assistant that combines classical machine learning, deep learning, retrieval-augmented generation, and agentic AI.

The system contains three connected components:

1. A return-risk prediction pipeline trained on a deterministic synthetic order-history dataset.
2. A product-image categoriser trained using transfer learning on Fashion-MNIST.
3. A LangGraph-based support assistant that can answer policy questions using a local knowledge base and can call both trained machine-learning models as tools. Part 3 uses a deterministic MOCK_LLM response generator.
LangGraph orchestration, RAG retrieval, and real ML tools are functional.
No external LLM API is required.

The final support assistant connects the models from Parts 1 and 2 instead of treating them as independent exercises.

- Five product categories
- Four payment methods
- Thirteen columns

### macOS Runtime Configuration

The project uses PyTorch, FAISS, Sentence Transformers, and
scikit-learn together. On macOS, native thread parallelism can
cause instability when these libraries are initialized in the
same process.

The application therefore limits native threading:

- `OMP_NUM_THREADS=1`
- `MKL_NUM_THREADS=1`
- `TOKENIZERS_PARALLELISM=false`

These settings improve runtime stability and do not affect the
model architecture or prediction logic.
